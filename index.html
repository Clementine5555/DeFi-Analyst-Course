Data & On-Chain Intelligence

SQL di Dune, Python dasar untuk data, AI agents sederhana

2–3 bulan
▾
TUJUAN FASE Kamu bisa nulis SQL sendiri di Dune, pull data on-chain dengan Python (pakai AI bantuin coding-nya), dan bikin AI agent sederhana yang automasi bagian dari workflow riset kamu.
💡 UNTUK NON-CODER SEPERTI KAMU Gunakan Claude/Cursor untuk bantu nulis SQL dan Python. Fokus pada pemahaman logika — kamu harus bisa baca kode, modifikasi, dan debug dengan bantuan AI. Tidak harus hafal syntax. Ini adalah "AI-assisted coding" skill yang sangat valuable di 2026.

SQL untuk On-Chain Data

  • SELECT, WHERE, GROUP BY, ORDER BY
  • JOIN antar tabel (transactions + prices)
  • Window functions (running total, rank)
  • CTEs (WITH clause) untuk query kompleks
  • Dune Spellbook tables
  • Time-series aggregation
  • Wallet cohort analysis via SQL

Python Dasar untuk Data

  • Pandas: load, clean, filter data
  • Requests: API calls (DeFiLlama API)
  • Matplotlib/Plotly: basic charts
  • Jupyter Notebook workflow
  • DuneClient Python library
  • Web3.py basics (read-only)
  • Automasi report sederhana dengan Python

AI Agents Sederhana

  • Apa itu AI agent? (LLM + tools + loop)
  • Claude API: basic integration
  • Build simple agent: DeFi data fetcher + interpreter
  • LangChain basics (opsional tapi valuable)
  • Scheduled agents: cron job + Python + LLM

🧠 Judgment & Context

AI bisa pull data, tapi kamu yang tahu "ini bullshit atau legit." Kemampuan mendeteksi rug pull, memahami motivasi tim, dan baca situasi pasar — ini tetap human skill.

🔗 Network & Relationships

Akses ke insider info, early deals, dan private research pools datang dari network manusia. AI tidak bisa bikin kamu dikenal di komunitas DeFi.

📐 Framework Building

Merancang metode evaluasi baru, risk framework original, atau scoring system yang belum pernah ada — ini kreativitas analitis yang AI replicate dengan susah.

🎯 Narrative Craft

Bisa jelaskan complex DeFi concept ke investor awam, atau tulis riset yang benar-benar dibaca orang — bukan hanya AI-generated walls of text.

⚡ Real-time Decision Making

Saat exploit terjadi, market crash, atau opp muncul dalam 30 menit — kecepatan dan judgment manusia di bawah tekanan tetap critical.

🛠️ AI Tool Orchestration

Ironis tapi benar: skill menggunakan AI secara efektif adalah skill yang AI tidak bisa gantikan. Orang yang tahu cara "direct the orchestra" tetap in demand.

Tips untuk Orang Indonesia
