# DeFi Analyst Course

Personal learning roadmap for becoming an AI-Powered DeFi Analyst.

Built as a single-page HTML document covering 6 phases — from DeFi fundamentals and prompt engineering, all the way to building AI agents for on-chain analysis and portfolio building.

Designed for self-study at 10–15 hours per week, with an estimated timeline of 12–18 months to reach junior analyst level.
